# RestroSuite

RestroSuite is a restaurant management system built with Angular 16. The project follows a modular architecture and uses Angular Material.

## Tech Stack

- Angular 16
- TypeScript
- Angular Material
- SCSS

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
ng serve
```

Open the application at:

```
http://localhost:4200
```

## Build

Generate a production build:

```bash
ng build
```

The build output will be available in the `dist/` directory.

## Running Tests

Run unit tests:

```bash
ng test
```

## Available Scripts

```bash
npm start
npm run build
npm test
npm run lint
```
